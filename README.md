# NMR-Spectra-Analysis-Portfolio
Independent molecular structure elucidation using 1D NMR spectrum data
## Project Objective
To independently resolve, analyze, and validate the molecular structure  of an unknown compound using raw 1D 1H and 13C NMR spectrum data retrieved from public chemical repositories. This project demonstrates practical proficiency in analytical chemistry data interpretation for chemical quality control or AI data annotation pipelines.
